Comandos para Linux

O que são comandos do Linux?

São códigos executados no terminal que permitem realizar diversas tarefas, como:

  • Criar pastas
  • Executar arquivos
  • Instalar programas
  • Entre muitas outras funcionalidades

Atalhos do terminal:

  1. Ctrl + Alt + T - Abre o terminal (em muitas distribuições)
  2. Ctrl + L - Limpa o terminal (igual ao comando clear)
  3. Ctrl + C - Cancela um comando em execução
  4. Ctrl + D - Fecha o terminal
  5. Ctrl + A - Vai para o início da linha
  6. Ctrl + E - Vai para o final da linha
  7. Tab - Autocompleta comandos e caminhos
  8. Seta ↑ - Mostra o último comando usado
  9. Seta ↓ - Navega entre comandos anteriores
  10. Ctrl + U - Apaga tudo antes do cursor
  11. Ctrl + K - Apaga tudo depois do cursor

Comandos básicos:

  1. cd - Entra em diretórios.
    Ex: cd Documentos
  2. ls - Lista arquivos do diretório.
  3. pwd - Mostra o diretório atual.
  4. clear - Limpa o terminal.
  5. mkdir - Cria uma pasta.
  6. nano - Editor de texto no terminal.
  7. touch - Cria um arquivo vazio.

Caminhos:

  • . - Diretório atual
  • .. - Volta um diretório

Gerenciamento de arquivos:

  1. mv - Move ou renomeia arquivos.
    Ex: mv arquivo.txt novo_nome.txt
  2. cp - Copia arquivos.
    Ex: cp arquivo.txt copia.txt
  3. rm - Remove arquivos.
    Ex: rm arquivo.txt
    Obs: Use com cuidado, pois não vai para a lixeira.
  4. rename - Renomeia vários arquivos de uma vez.
    Ex: rename 's/.png/.jpg/' *.png

Sistema (APT):

  1. sudo apt - Gerenciador de pacotes para distribuições baseadas em Debian.
  2. sudo apt update - Atualiza a lista de pacotes.
  3. sudo apt install - Instala programas.
    Ex: sudo apt install nome-do-programa

Execução de arquivos:

  • python3 arquivo.py
  • ./script.sh
  • xdg-open arquivo.html
