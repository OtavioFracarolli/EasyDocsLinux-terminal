Comandos para Linux

O que são comandos do Linux?

São códigos executados no terminal que permitem realizar diversas tarefas, como:

  • Criar pastas
  • Executar arquivos
  • Instalar programas
  • Entre muitas outras funcionalidades

Atalhos do terminal:

  1. Ctrl + Alt + T - Abre o terminal (em muitas distribuições)
  2. Ctrl + L - Limpa o terminal (igual ao comando clear)
  3. Ctrl + C - Cancela um comando em execução
  4. Ctrl + D - Fecha o terminal
  5. Ctrl + A - Vai para o início da linha
  6. Ctrl + E - Vai para o final da linha
  7. Tab - Autocompleta comandos e caminhos
  8. Seta ↑ - Mostra o último comando usado
  9. Seta ↓ - Navega entre comandos anteriores
  10. Ctrl + U - Apaga tudo antes do cursor
  11. Ctrl + K - Apaga tudo depois do cursor

Comandos básicos:

  1. cd - Entra em diretórios.
    Ex: cd Documentos
  2. ls - Lista arquivos do diretório.
  3. pwd - Mostra o diretório atual.
  4. clear - Limpa o terminal.
  5. mkdir - Cria uma pasta.
  6. nano - Editor de texto no terminal (também cria o arquivo se não existir).
  7. touch - Cria um arquivo vazio.

Caminhos:

  • . - Diretório atual
  • .. - Volta um diretório

Gerenciamento de arquivos:

  1. mv - Move ou renomeia arquivos.
    Ex: mv arquivo.txt novo_nome.txt
  2. cp - Copia arquivos.
    Ex: cp arquivo.txt copia.txt
  3. rm - Remove arquivos.
    Ex: rm arquivo.txt
    Obs: Use com cuidado, pois não vai para a lixeira.
  4. rename - Renomeia vários arquivos de uma vez.
    Ex: rename 's/.png/.jpg/' *.png
    Obs: Pode ser necessário instalar com sudo apt install rename

Sistema (APT):

  1. sudo apt - Gerenciador de pacotes para distribuições baseadas em Debian.
    Ex: Linux Mint, Zorin OS, Ubuntu
  2. sudo apt update - Atualiza a lista de pacotes disponíveis no sistema.
  3. sudo apt install - Instala programas no sistema.
    Ex: sudo apt install nome-do-programa
    Obs: Arquivos .deb também podem ser instalados, mas não são obrigatórios.

Execução de arquivos:

  • python3 arquivo.py - Executa arquivo Python
  • ./script.sh - Executa script
  • xdg-open arquivo.html - Abre HTML no navegador

Comandos estéticos:

  1. sudo apt install lolcat - Colore textos.
    Ex: echo "Olá, mundo" | lolcat
  2. sudo apt install figlet - Cria textos grandes.
    Ex: figlet Linux
  3. sudo apt install tree - Mostra arquivos em forma de árvore.
  4. sudo apt install htop - Mostra uso de CPU, RAM e processos.
  5. sudo apt install neofetch - Mostra informações do sistema.

Comandos engraçados:

  1. sudo apt install cmatrix - Efeito estilo Matrix.
  2. sudo apt install oneko - Gatinho que segue o mouse.
  3. sudo apt install cowsay - Vaca que “fala” um texto.
  4. sudo apt install fortune - Frases aleatórias.
  5. sudo apt install sl - Exibe um trem no terminal.

Dicas:

  • Use sudo apenas quando necessário
  • Tenha cuidado com rm -rf
